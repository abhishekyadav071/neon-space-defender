# 🎮 Neon Space Defender

A 2D browser-based space shooter game built using **HTML, CSS, and JavaScript (Canvas API)**.  
Enjoy a fast-paced arcade experience with enemies, power-ups, and boss fights.

---

## 🚀 Features
- 🎯 Smooth player movement (WASD / Arrow Keys)
- 🔫 Shooting mechanics with sound effects
- 👾 Dynamic enemies and boss battles
- ⭐ Power-ups (Shield, Double Bullets, Speed Boost)
- 🏆 Leaderboard system using LocalStorage
- 🎨 Neon-themed UI with glowing effects

---

## 🧠 Tech Stack
- HTML  
- CSS  
- JavaScript (Canvas API)

---

## 🎮 How to Play
- Move: Arrow Keys / WASD  
- Shoot: Spacebar  
- Defeat enemies and survive as long as possible
